# Shur-loc Media Tools

WordPress plugin providing Media Library management and SEO tools for the Shur-loc website.

## Features

- Adds an **Alt Text** column to the WordPress Media Library.
- Adds an **SEO Status** indicator for image alt text.
- Identifies attachments with missing alt text.
- Filters the Media Library by missing or present alt text.
- Provides sortable alt-text information.
- Adds lightweight Media Library admin styling.

## Requirements

- WordPress
- PHP 8.0 or later

## Development

The plugin uses PHPUnit, PHPStan, and WordPress Coding Standards for automated testing and static analysis.

Plugin classes and tests use the `Shurloc\MediaTools` namespace.
